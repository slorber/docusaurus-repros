# Repro: facebook/docusaurus#7606

Issue: https://github.com/facebook/docusaurus/issues/7606

**Result: the bug no longer reproduces with Docusaurus `4.0.0-canary-6972`.**

## The bug

A page using code generated by [protobuf-ts](https://github.com/timostamm/protobuf-ts) crashed in production with `TypeError: class constructors must be invoked with 'new'`. Babel's `loose` mode ([`superIsCallableConstructor`](https://babeljs.io/docs/assumptions#superiscallableconstructor)) compiled the site's `class Person$Type extends MessageType` to call `super` as a plain function, but `MessageType` comes from `node_modules`, isn't transpiled, and stays a native class.

Docusaurus v4 transpiles with SWC by default, which calls `super` through `Reflect.construct`.

## Setup

- `src/proto/msg.ts`: the code protobuf-ts generated in the [original repro](https://github.com/devalbo/docusaurus-protobuf-test), using the real `@protobuf-ts/runtime` package.
- `src/pages/index.tsx`: encodes and decodes a `Person` during SSR, and again on the client in `useEffect`.
- `package.json`: the production Browserslist is `ie 11`. It forces the site's classes to be transpiled to ES5 functions, the condition that triggered the bug. Open the page in a modern browser anyway.

## Steps

Requires Node.js >= 24.21.

```bash
npm install
npm run build
npm run serve
```

Open http://localhost:3000/

## Expected result

```
SSR ok: Person {"name":"Ada","baz":36}
client ok: Person {"name":"Ada","baz":36}
```

No error in the browser console.

## Seeing the bug with the deprecated Webpack mode

The deprecated Webpack + Babel mode still compiles with Babel's `loose` mode, and still has the bug:

1. Add `webpack: true` to `docusaurus.config.js`
2. `npm run clear && npm run build -- --no-minify` (`--no-minify` avoids unrelated minification errors in this mode)
3. `npm run serve`

The page shows `client not run: ...` and the browser console shows `TypeError: Class constructor MessageType cannot be invoked without 'new'`.

In this mode, the workaround from the issue still works: add a `babel.config.js` file, then clear and rebuild.

```js
module.exports = {
  presets: [require.resolve('@docusaurus/babel/preset')],
  assumptions: {superIsCallableConstructor: false},
};
```
